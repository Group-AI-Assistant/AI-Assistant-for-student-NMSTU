# RAG — запуск

## Быстрый старт

1) Сначала нужно скачать Ollama (для запуска нейросетей на локальном компьютере(LLM))
скачиваем с официального сайта <https://ollama.com/download/windows>

2) Убедитесь, что у вас установлен Python: желательно, версии 3.12 - 3.14. 
Можно скачать с официального сайта: <https://www.python.org/downloads/> 
Либо (удобнее) на Microsoft Store: https://apps.microsoft.com/detail/9NCVDN91XZQP?hl=neutral&gl=RU&ocid=pdpshare

3) Скачайте, распакуйте проект, откройте папку проекта.
Далее откройте Powershell или CMD в папке проекта. Впишите команды: 
```cmd
# Создать окружение (если еще нет)
python -m venv venv

# Активировать окружение
venv\Scripts\activate # powershell
venv\Scripts\activate.ps1 #cmd

# Установить зависимости
pip install -r requirements.txt

# Потом скачиваем нужную LLM
ollama pull qwen2.5:3b                    
```

## Запуск

Ollama должен быть запущен и модель `qwen2.5:3b` должна быть скачана.
Модель эмбеддингов подтянется автоматически при запуске.

На диске C:\\ должно быть свободно хотя бы 4.5 ГБ, потому что при запуске будут подтягиваться увесистые библиотеки. Позже их можно вручную удалить. Установленные библиотеки (увесистые, возможно все) можно найти по пути: C:\Users\\ваш user\\.cache
```cmd
venv\Scripts\activate # (если не запущена)
python app.py
```
После запуска открыть `http://127.0.0.1:5000` в браузере.

Если возникли ошибки при запуске app.py (загрузке поисковой модели), то попробуйте включить VPN, либо Zapret Discord Youtube + WARP 1.1.1.1.

## Бенчмарк

Бенчмарк берет "вопросы | ответы" из файла "Вопросы для Benchmark.txt" в папке "data". Файл должен называться именно так. Пример вопросов приложен там же. Одна строка - один "вопрос | ответ".

Замените "вопросы | ответы" на свои и откройте Ассистента в браузере. 
Там перейдите на вкладку "Бенчмарк" и запустите бенчмарк. Дождитесь окончания. (Ориентировочно 20-50 минут при 100 вопросах). Сохраните результат в json.

Результат сохранится в папке \benchmark_reports. 

### Конвертация в DOCX
Переименуйте json-файл в "benchmark.json".
В терминале (cmd/powershell) остановите сервер (Ctrl+C).
Впишите:
```cmd
venv\Scripts\activate # (если не запущена)

cd benchmark_reports
python benchmark_to_docx.py
```
