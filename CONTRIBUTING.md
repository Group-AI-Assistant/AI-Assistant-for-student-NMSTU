**Как добавить документ через веб-интерфейс:**
1. Откройте репозиторий на GitHub
2. Перейдите в нужную папку где должен быть документ
3. Нажмите кнопку "Add file" → "Create new file" или найдите существующий файл и нажмите иконку карандаша для редактирования
4. Введите название файла с расширением .md (например, modul-nazvanie.md)
5. Напишите содержимое в редакторе. Используйте markdown разметку
6. Прокрутите вниз до блока "Commit changes"
7. В поле "Commit message" напишите краткое описание изменений
8. Выберите опцию "Create a new branch for this commit and start a pull request"
9. Нажмите "Propose changes"
10. На странице Pull Request проверьте изменения и нажмите "Create pull request"
11. Дождитесь проверки коллегами
