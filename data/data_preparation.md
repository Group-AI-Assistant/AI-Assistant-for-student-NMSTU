**Проблемы при подготовке данных**

Сбор данных из VK API сталкивается с проблемой малой вариативности настроек при получении постов. Полученные данные имеют в себе #Хэштеги, встроенные в текст #хэштеги, полные ссылки https://blablabla, короткие ссылки @club1234, причем смысл постов порой заключен в этих ссыылках ("Подробности в [https://...album|альбоме] "). Сбор данных из документов и текста официального сайта сталкивается с проблемой -(эта часть не дописана)

**Принятые решения**
- использовать способ разбиения чанков по абзацам (по смыслу);
- не удалять хэштеги из данных постов VK, ассистент будет игнорировать хэштеги с помощью системного промпта.

**Правила обновления базы знаний**
- Ответственный вручную проверяет официальный сайт на наличие обновлений в документах, ранее занесенных в нашу базу знаний.
- Ответственный с помощью скрипта получает данные с VK API по всем группам за прошедший неохваченныый период (полгода).
- Ответственный добавляет найденные документы и полученные данные в базу знаний (делит на чанки, превращает в эмбеддинг, сохраняет в векторной базе данных)
- Ответственный задает тестовые вопросы по новым данным ИИ-ассистенту. Если ответы не устраивают, то ответстенный или решает проблему, или обращается к разработчику за помощью.
- Ответственный документирует занесенные документы и данные в папке data/updates/ новым файлом update_%data%.
